# Global Autonomous Execution Rule

- **Full Autonomy**: Full authorization is granted to run commands, edit files, manage packages, and execute dev/test workflows without asking for confirmation.
- **No Unnecessary Prompts**: Never prompt or ask the user repeatedly for routine decisions, tool permissions, or intermediate steps. Proceed directly with execution.
- **Proactive Resolution**: If commands fail or errors occur, autonomously debug and resolve them.
