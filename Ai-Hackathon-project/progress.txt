1. EXECUTIVE PRODUCT OVERVIEW & BRAND IDENTITY
================================================================================
Daymark reimagines the morning news routine as a finite, elegant, high-signal
digital broadsheet. Instead of endless algorithmic dopamine feeds, Daymark delivers
a personalized morning newspaper curated to the reader's intellectual lenses,
complete with an executive 3-takeaway intelligence box, lead cover story, audio
dispatch, and a deliberate "Outside Your Bubble" blindspot section to prevent
echo chambers.

- Product Name: DAYMARK
- Official Tagline: "Your world, clearly delivered."
- Visual Aesthetic: Dual-theme editorial broadsheet:
  * "Daily Broadsheet" (Light Mode): Warm ivory canvas (#F7F5EF), deep ink charcoal
    typography (#20211F), crisp borders (#E5DFD1), and forest green accents.
  * "Midnight Editorial" (Dark Mode): Rich midnight navy (#07111F / #0D1B2C),
    luminous typography (#F1F5FA), and vibrant cobalt blue accents (#526BFF).
- Core Principles:
  * Finite Reading Experience: 5, 15, or 30-minute editions calibrated to reader pace.
  * Transparent Scoring: Explainable algorithmic relevance scores (0-100%) on every story.
  * Privacy Sovereignty: Zero ads, zero commercial tracking, and client-side storage.
  * Contextual Printing: Per-edition Print/PDF engine producing ink-saving paper broadsheets.

2. ZERO-BUDGET ARCHITECTURAL COMPLIANCE (PKR 0 TOTAL BUDGET)
================================================================================
Every subsystem operates at strictly $0.00 cost with no credit card requirement:

1. News Ingestion: 100% Free Public RSS Feeds (BBC News, The New York Times,
   Ars Technica, NPR News). Fast parallel server-side fetch with 5-minute caching
   (next: { revalidate: 300 }) and 6-second timeout abort controllers.
2. AI / Executive Synthesis:
   - Free Google Gemini 1.5 Flash via REST API (using free Google AI Studio keys).
   - Deterministic Fallback Engine: When no API key is set, all summaries, takeaways,
     and algorithmic explanations execute locally with zero latency.
3. Audio Dispatch Engine: Native Browser Web Speech API (SpeechSynthesis). 100%
   free, client-side, zero token limits or recurring charges.
4. Database & Storage:
   - Primary: MongoDB Cloud (Mongoose ODM) with cached connection pooling.
   - Resilient Fallback: Atomic local JSON database at `data/daymark_db.json`.
5. Email Dispatch: Nodemailer service with standard SMTP support and automated
   simulated fallback for testing without configured mail servers.
6. PDF Broadsheet Export: Browser `@media print` CSS engine in `globals.css`
   producing pure-white, high-contrast, multi-column paper broadsheets.
7. Hosting & CI/CD: Vercel Hobby Tier auto-deploying on every Git push to `main`.

3. FULL ROUTE INVENTORY (21 COMPILED ROUTES & EDGE MIDDLEWARE)
================================================================================
The application compiles 21 static/dynamic routes and an edge security layer:

1. `/` (Today's Live Morning Broadsheet) [PROTECTED]:
   - 3-Tier Professional Header: Utility Bar, Centered Masthead, Editorial Section Row.
   - Executive 3-Takeaway Intelligence Box synthesized from top stories.
   - Lead Cover Story with headline, drop cap, reading time pill, and live likes counter.
   - Front Page Priority Reports with topic badges, relevance match %, and likes counter.
   - The Morning Wire sidebar with compact inline like buttons and fast dispatch.
   - "Outside Your Bubble" blindspot section to combat confirmation bias.
   - Real-Time Likes Counter: Interactive thumbs up button with instant state update.
   - Contextual Print / PDF Export Button: Exports only the active newspaper edition.

2. `/dashboard` (Daymark Page Directory):
   - Grid view of all 9 editorial broadsheet sections (Technology, World, Markets,
     Science, Health, Climate, Culture, Commentary, Saved Clippings).
   - Dynamic article counters, quick-filter shortcuts, and subscriber statistics.

3. `/login` (Press Room Sign-In):
   - Authenticates existing subscribers against MongoDB credentials via `/api/auth/login`.
   - 1-Click "Instant Demo Login (Judge Access)" pre-authenticates `DEMO_JUDGE_USER`.
   - Seamlessly prompts unverified users for email OTP verification.

4. `/signup` (Subscription Desk):
   - Fields: Full Name, Subscriber Email, Password, Custom Newspaper Title.
   - Submits to `/api/auth/register`, registers user in MongoDB (`isVerified: false`),
     issues a 6-digit OTP code to subscriber's email, and redirects to `/verify-otp`.

5. `/verify-otp` (Press Verification Desk):
   - 6-digit auto-advancing OTP digit inputs with paste support.
   - Quick-Fill sample button (code `742891`) for rapid demonstration.
   - Validates code via `/api/auth/otp/verify`, updates MongoDB to `isVerified: true`,
     sets session cookies, and enters the morning broadsheet.

6. `/onboarding` (Editorial Calibration Desk):
   - 3-Step Broadsheet Setup: Core editorial sections, keyword lenses, reading pace.

7. `/archive` (Historical Broadsheet Registry):
   - Preserves historical daily editions by date snapshot.
   - Interactive Reader Modal and contextual edition-only printing.

8. `/profile` (The Learning Brain & Recommendation Telemetry):
   - Real-time affinity gauges across 8 editorial desks (0-100%).
   - Engagement audit trail and AI Suggested Interests desk.

9. `/about` (Editorial Mission & Architecture):
   - Explains Daymark's deterministic curation, zero-hallucination policy, and ethics.

10. `/privacy` (Privacy Policy & Data Sovereignty):
    - Details 100% client-side storage, cookie usage, and zero third-party telemetry.

11. `/api/news` (GET):
    - Fetches and parses RSS feeds, hydrates articles with persistent likes from MongoDB.

12. `/api/articles/like` (POST/GET):
    - Atomically increments/decrements article likes in MongoDB and retrieves likes maps.

13. `/api/auth/register` (POST):
    - Registers new subscriber in MongoDB, generates 6-digit OTP, dispatches email.

14. `/api/auth/login` (POST):
    - Authenticates existing users against MongoDB and verifies email status.

15. `/api/auth/otp/send` (POST):
    - Issues a fresh 6-digit verification code and dispatches email via Nodemailer.

16. `/api/auth/otp/verify` (POST):
    - Validates code against MongoDB and establishes authenticated session cookies.

17. `/api/auth/me` (GET):
    - Returns current authenticated subscriber identity.

18. `/api/ai/gemini` (POST):
    - Server-side executive summary generation via Google Gemini 1.5 Flash.

19. `/api/ai/learn` (GET/POST):
    - Real-time adaptive AI learning signal processing and suggested interest generation.

20. `middleware.ts` (Edge Security Layer):
    - Protects `/`, `/onboarding`, `/profile`, `/archive` routes via cookie validation.

4. CORE ENGINE IMPLEMENTATIONS & ALGORITHMIC LOGIC
================================================================================
1. Deterministic Multi-Factor Ranking Engine (`lib/ranking.ts`):
   - Relevance Score = (Topic Affinity * 35%) + (Keyword Matches * 30%) +
     (Source Quality * 15%) + (Recency Decay * 20%) - Penalty Modifiers.
   - Transparent scoring breakdown displayed in the "Why this?" modal.

2. Adaptive Learning Signals Engine (`lib/storage.ts` & `/api/ai/learn`):
   - Upvoting / Liking boosts topic affinity (+1.5) and elevates keyword scores.
   - Downvoting / Dismissing penalizes topic affinity (-1.2) to refine future editions.
   - Dynamic interest suggestion discovers emerging topics based on reading history.

3. Live Post Likes Counter Engine:
   - Articles carry `likesCount` hydrated from MongoDB.
   - Instant optimistic UI update on click (+1/-1) with toast confirmation.
   - Atomic persistence to MongoDB via `findOneAndUpdate` with user tracking.

================================================================================
5. AUTHENTICATION, SECURITY & EMAIL OTP VERIFICATION SYSTEM
================================================================================
- Double-Authentication Flow:
  * Sign Up: Submits user data -> Stores unverified user in MongoDB -> Issues 6-digit OTP
    via email (`lib/email.ts`) -> User verifies OTP -> Account activated with cookies.
  * Sign In: Validates email & password in MongoDB -> Verifies email confirmation ->
    Sets authenticated session cookies (`daymark_token`, `daymark_otp_verified`).
- Email Dispatch:
  * Production SMTP: Configured via `EMAIL_SERVER_HOST`, `EMAIL_SERVER_PORT`,
    `EMAIL_SERVER_USER`, `EMAIL_SERVER_PASSWORD`. Dispatches broadsheet HTML emails.
  * Dev / Testing Fallback: When SMTP is omitted, logs code to console and provides
    instant code preview in response for zero-friction evaluation.
- Hackathon Judge Access: Pre-configured sample credentials (`742891`) allow 1-click
  evaluation without requiring an external email mailbox.

================================================================================
6. DATA PERSISTENCE & DATABASE SCHEMAS (MONGODB + LOCAL FALLBACK)
================================================================================
- Mongoose Database Models:
  * `User`: `{ id, name, email, password, paperTitle, isVerified, otpCode, otpExpiresAt, preferences, createdAt }`
  * `Otp`: `{ email, code, expiresAt, verified, createdAt }` (with 1-hour TTL auto-deletion)
  * `ArticleLike`: `{ articleId, likesCount, likedUserEmails, updatedAt }`
- Local File Fallback: `data/daymark_db.json` mirrors all schemas to guarantee zero-crash
  operation if MongoDB connection strings are omitted or offline.
