## 2. Platform Free-Tier Limits & Mitigations
| Service | Free Tier Limits | Mitigation / Status |
| :--- | :--- | :--- |
| **Public RSS Feeds** | Rate limiting if queried excessively per second | Server-side 5-minute caching (`next: { revalidate: 300 }`) and 6s timeout abort controller to prevent rate-limit bans |
| **Web Speech API** | Browser-dependent voice synthesizers | Native client-side speech synthesis; runs fully local with 0 network or subscription overhead |
| **Vercel Hobby** | 100GB bandwidth/mo, 10s serverless function timeout, 100 deployment/day | Lightweight payload (<104KB), parallel RSS fetch finishes in ~600ms, well within all free limits |
| **Browser Storage** | ~5MB localStorage quota per domain | Compact JSON storage; saved editions capped at 20 snapshots; clippings store IDs and metadata |
| **Browser Print** | Dependent on client browser PDF driver | Standardized CSS print broadsheet rules, explicit dialog instructions for "Save as PDF" |

## 6. Deployment Guide (PKR 0 Cost)
### Deploying to Vercel (Recommended):
1. Push your latest code to GitHub:
   ```bash
   git push origin main
   ```
2. Go to [https://vercel.com/new](https://vercel.com/new) and log in with your GitHub account (No credit card required).
3. Import the `Ai-Hackathon-Project` repository.
4. If prompted for **Root Directory**, select `Ai-Hackathon-project` (or let `vercel.json` handle it).
5. Click **Deploy**. Vercel will build and assign a free production URL (e.g. `https://morning-chronicle.vercel.app`).
