## ⚡ Quick Start: Running the Project

The application is built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

### Option A: From Repository Root (`D:\Git-Hub Repo`)
```bash
# Run the development server
npm run dev

# Or run the production build
npm run build
npm run start
```

### Option B: From Application Subfolder (`Ai-Hackathon-project`)
```bash
cd Ai-Hackathon-project

# Run the development server
npm run dev

# Or run the production build
npm run build
npm run start
```

Once running, open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 📰 About Daymark
Daymark reimagines the morning newspaper as a quiet, thoughtful, and beautifully typeset daily broadsheet inspired by modern editorial publications like *Tide* and *The Atlantic*:
- **Warm Ivory Palette**: Ivory `#F7F5EF`, Charcoal `#20211F`, and Forest Green `#496653`.
- **Live Parallel RSS Feeds**: Real-time verified articles from BBC News, The New York Times, Ars Technica, and NPR News (100% zero hallucination, zero API key cost).
- **Explainable Ranking Engine**: Transparent 0–99% personal relevance scoring with a breakdown modal ("Why this?").
- **1-Click Audio Dispatch**: Browser-native Web Speech API morning briefing.
- **Morning Editions Archive & Broadsheet Print**: Save past editions to `localStorage` and print or export to PDF with `@media print`.

For full documentation and architecture details, see [Ai-Hackathon-project/README.md](file:///d:/Git-Hub%20Repo/Ai-Hackathon-project/README.md).
